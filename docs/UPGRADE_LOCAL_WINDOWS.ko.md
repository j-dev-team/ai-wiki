# Windows 로컬 AI Wiki 업그레이드 확인

로컬 단독 위키의 upgrade는 패키지 설치 성공만으로 끝나지 않는다. 다음 네 가지를
모두 확인한다.

1. 대상 CLI와 패키지 버전이 기대 버전인지 확인한다.
2. 정식 `<skill_name>/SKILL.md`의 version과 SHA-256이 번들 템플릿과 같은지 확인한다.
3. 대상 위키에서 `doctor`를 실행해 문서·색인·벡터 상태를 확인한다.
4. 명령이 종료된 뒤에도 `ai-wiki.exe` 또는 variant CLI가 남아 파일 잠금을 유지하지
   않는지 확인한다.

`upgrade-skill`은 스킬 파일의 해시·버전을 출력하고, 다른 프로세스를 자동 종료하지
않는다. 잠금이 발견되면 PID와 실행 명령을 사용자가 확인한 뒤 로컬 서버를 정상 종료하고
재시도한다. 강제 종료는 저장 중인 위키 데이터를 손상시킬 수 있으므로 자동화하지 않는다.

복구가 필요하면 `.ai-wiki-skill-backups/`의 별칭 백업을 복원하고, 정식 스킬 경로를
다시 감사한 뒤 `doctor`와 `vindex`를 순서대로 실행한다.
